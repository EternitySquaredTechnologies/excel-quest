# Excel Quest

A browser game for practising Excel formulas and PivotTables. Players pick Excel 2016 or Excel 2021 / 365, then work through missions on a small sales sheet: totals, text cleaning, IF, COUNTIF and SUMIF, lookups, dates, data cleaning, modern array functions and PivotTables.

Play it at https://eternitysquaredtechnologies.github.io/excel-quest/

Progress is kept in the browser. A save code moves it to another device. No accounts.
